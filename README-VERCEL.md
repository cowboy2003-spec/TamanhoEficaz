# Tamanho Eficaz — Demo Vercel

## Local
npm install
npm run dev

## Validar antes do deploy
npm run build

## Vercel
1. Criar um repositório Git (GitHub/GitLab/Bitbucket) e enviar esta pasta.
2. No Vercel, New Project -> importar o repositório.
3. Framework: Next.js (deteção automática).
4. Build command: npm run build.
5. Deploy.

Esta é uma demo comercial. Antes de substituir o site oficial devem ser validados:
- textos legais/RGPD e funcionamento real dos formulários;
- estado atual das certificações;
- propriedade/uso autorizado de fotografias e logótipos;
- dados empresariais e números apresentados;
- domínio e DNS.
