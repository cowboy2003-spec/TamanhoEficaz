# Tamanho Eficaz V2 — apresentação
Versão visual pronta para demonstração, construída a partir do site público, pesquisa factual e imagens reais do portefólio fornecidas.

## Executar
npm install
npm run dev

Abrir http://localhost:3000

## Produção
Antes de publicar como site oficial: validar certificações, textos legais, âmbito técnico dos projetos, formulários, armazenamento, e-mail, RGPD, traduções e substituir imagens genéricas de serviços por ativos aprovados quando disponíveis.


## Branding
Logótipo real fornecido para o projeto integrado no header e footer em PNG transparente.
